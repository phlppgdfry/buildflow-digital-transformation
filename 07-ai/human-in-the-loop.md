# Human review workflow

1. Coordinator requests optional draft and sees source facts plus missing fields.
2. UI labels generated suggestion and prohibits decision fields.
3. Reviewer compares facts, edits any wording and accepts selected fields or dismisses.
4. Audit stores suggestion, accepted fields, reviewer, UTC and prompt/model version.
5. Normal claim validations and Manager/Finance approvals still apply independently.

A reviewer is accountable for the accepted content, not for trusting a score. If the description is ambiguous, ask the reporter rather than guessing. Liability remains Unknown until a human documents evidence and assessment. Demo review stores an explicit decision but never directly alters claim status/financial authority.
