# UAT plan

Business owner sponsors a two-day rehearsal and five-day supervised pilot UAT. Warehouse/Key User run Inventory; Coordinator/Manager/Finance run Claims; IT observes exceptions without choosing business outcomes.

Entry: agreed requirements, clean migration sample, role/project matrix, training, stable build, restored test environment and ERP sandbox. Execute 24 scenarios, at least two negative permission cases per role, offline/restore exercise and a real-style invoice lifecycle.

Each result records build, tester, input, expected/observed behaviour, run/correlation ID, defect, retest and owner decision. Exit: all Must criteria pass, no Sev1/2 open, known Should limitations accepted, access and reconciliation evidence attached. A prepared template is not a completed sign-off. Unimplemented demo features cannot be marked passed as production requirements.
