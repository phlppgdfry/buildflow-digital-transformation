# Training plan

| Group | Session | Practice / pass check |
|---|---|---|
| Field employee | 20min on device | Create draft/evidence, see unconfirmed offline state |
| Warehouse | 45min hands-on | Checkout, clean/damaged return, transfer receipt, lost exception |
| Manager | 25min | Evidence review, rejection reason, delegation, no self-approval |
| Finance | 40min | High-value approval, reference lookup and invoice mismatch |
| Key users | 60min | Explain exception/fallback, capture defect, coach colleague |
| IT support | 60min incident rehearsal | Queue failure, dedup replay and reconciliation |

Use synthetic devices/data in training. A champion per pilot site and backup per shift. Dutch materials at pilot; French materials and rehearsal before French-speaking site rollout. Assess by task completion, not attendance. Short refresher follows observed friction.
