# Stakeholder impact

| Role | Change / potential resistance | Response / success evidence |
|---|---|---|
| Experienced Warehouse operator | Replaces familiar spreadsheet; fears slower tasks | Co-design scan/return; compare task times; keep expertise visible |
| Site employee | Named custody and evidence capture | Explain custody ≠ fault; short mobile steps; privacy boundaries |
| Warehouse manager | Inspection and reconciliation work | Staffing/time allocation; exception dashboard |
| Project manager | Time-bound versioned approval | Delegate rules and reminder preferences |
| Finance | Linked commitment/actual reconciliation | Walk through duplicate/timeout cases in ERP sandbox |
| IT | New supported service and connectors | Runbook, monitoring, rota and recovery rehearsal |
| Procurement | Must check custody before replacement | Faster search evidence; override with reason |

Resistance often signals a real workflow constraint. Record concerns as testable requirements; do not frame users as obstacles.
