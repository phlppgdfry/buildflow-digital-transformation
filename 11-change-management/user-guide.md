# Quick user guide

## Warehouse

Find the physical QR/asset ID, confirm status and location. Check out to an active site and named custodian; verify Assigned and history. At return inspect condition first. Clean return releases it; damaged return quarantines the asset and creates a Draft claim to complete. Claim rejection does not release unsafe equipment.

Transfer dispatch retains source custody until the receiving site confirms. If offline, label the draft unconfirmed and use the numbered outage receipt. On reconnection review conflicts with Warehouse; do not assume local save changed stock.

## Claims

Create Draft, describe facts, choose severity and add relevant minimised photos/documents. Submit only when the required evidence is complete. Coordinator reviews and may ask for information; the original resolution deadline remains. Manager/Finance approve within delegation rules. AI suggestions must be read and edited/dismissed; AI cannot decide fault or money.

Finance handles actual invoices in ERP. Closed needs reconciled actual cost and repair outcome. Support ticket: claim/asset ID, action/time and correlation ID, never private photo in a public channel.

For this local demo select a synthetic role in the header. Synthetic evidence references are for demonstration only; no real photos or employee data should be entered.
