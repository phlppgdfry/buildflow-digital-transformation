# Start here

**Independent portfolio case.** BuildFlow Group is fictional. This kit presents the existing case through a small number of evidence-led views.

## If you have 2 minutes

Read the [one-page executive summary](01-executive-summary.md) or [download the A4 PDF](exports/executive-summary.pdf). You will see the problem, my proposed approach, concrete outputs and role fit. [Recruiter view](recruiter-view.md) is the 90-second alternative.

## If you have 5 minutes

Follow the [five-minute story](demo/5-minute-story.md). Open [architecture](../ARCHITECTURE.md), then [return BPMN](../03-processes/bpmn/README.md#material-return). Finish with the distinction between design, tested simulation and pending production validation.

## If you have 15 minutes

Open the [eight-slide interview deck](exports/interview-deck.pptx), run the [two-minute prototype journey](demo/2-minute-demo.md), and follow one [traceability row](../02-requirements/requirements-traceability-matrix.md). For technical discussion use [ERP ownership](../05-integrations/erp-integration.md), [OpenAPI](../05-integrations/api-contracts/openapi.json) and the [runbook](../05-integrations/operations-runbook.md).
