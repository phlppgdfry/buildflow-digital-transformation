# LinkedIn project description

**Independent Digital Transformation Portfolio Case - Inventory & Damage Claims**

I developed an independent portfolio case for BuildFlow Group, a fictional Belgian construction company. The case explores fragmented equipment custody and manual damage-claim follow-up.

It connects stakeholder workshop methodology, AS-IS/TO-BE BPMN, requirements traceability, ERP/API ownership and integration resilience. Power Automate blueprints coordinate approvals and SLA follow-up; an optional AI assistant illustrates explicit human review.

UAT scenarios, a representative pilot, migration, rollback, training and adoption measures show how the proposed solution could be introduced. A public browser prototype and local API tests make selected process rules tangible.

The company, workshop records and business metrics are fictional. Target Microsoft/ERP integrations are not deployed, the AI demo is a mock, and no realised client benefits are claimed.
