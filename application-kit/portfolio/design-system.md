# Application-kit visual system

One font family: Arial (regular/bold), with sans-serif fallback on the web. White canvas, navy #102536 headings, teal #087f8c actions, neutral #5f7382 secondary text and #dce5eb dividers. Flat editorial landing sections alternate simple text/diagram layouts. Workspace uses the six explicitly requested evidence tiles and a quiet sidebar, not an operating-system metaphor.

References: five built-in Image Gen concepts in assets/design: hero, cases, architecture, delivery and workspace. They specify the complete presentation surface. Exact source facts and honesty labels override generated placeholder wording; no generated screen is used as an actual UI.

Typography: web hero 64px desktop /36px mobile, section headings 32px, body 16px; deck titles at least 32pt except compact diagram labels; PDF main titles 25pt, body 10.5-12pt. Controls have visible keyboard focus. Whitespace and alignment carry hierarchy; no decorative animation, neon or repeated marketing cards.

Every proposed architecture/metric and prepared UAT status is labelled. Source links use the same evidence identifiers as the manifest. Downloads belong to Level A/B; original repository files are Level C. [Export plan](../export-plan.md).

Concept images are layout studies only, not case evidence. Some generated wording is inaccurate; canonical case.json overrides it. The implemented UI contains no generated facts or fictional user profiles.
