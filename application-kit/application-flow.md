# Application flow

CV portfolio entry links to the public landing page. A recruiter sees challenge, role, six outputs and a one-page PDF. A hiring manager follows the five-minute story or seven-page case. The interview uses the eight-slide deck and two-minute linked-claim prototype. Technical discussion follows workspace source links into BPMN, architecture, OpenAPI and ERP reliability.

| Stage | Send/open | Purpose |
|---|---|---|
| Application | [CV one-line entry](career/cv-entry.md) + portfolio URL | One coherent entry |
| Recruiter | Landing page + [one-page PDF](exports/executive-summary.pdf) | Relevance within 90 seconds |
| Hiring manager | [Five-minute story](demo/5-minute-story.md) + [case PDF](exports/case-study.pdf) | Reasoning and delivery choices |
| Interview | [Deck](exports/interview-deck.pptx) + [two-minute demo](demo/2-minute-demo.md) | Present and demonstrate |
| IT deep dive | [Technical view](technical-view.md) + source links | Boundaries, dependencies and controls |

Tailor the top three requirements to the actual vacancy before applying. No messages are sent by this repository. [Role matrix](role-requirement-matrix.md).
