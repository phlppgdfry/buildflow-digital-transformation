# Pilot and phased rollout

Pilot one central warehouse, SITE-004 Oostende and SITE-005 Brugge; select a representative experienced operator and one lower-connectivity site, not only enthusiasts. Label/verify the pilot population and map project managers before opening transactions.

Daily pilot review checks physical/custody agreement, queue ageing, missing evidence and user task time. Exit after two weeks: ≥95% pilot movements recorded same shift, ≥98% sampled location agreement, no Sev1/2 defects, zero unreconciled financial duplicates, support ready and users can handle fallback. These are proposed gates, not achieved results.

At evaluation, decide Go / extend / stop. Roll out by BU/site in two waves with trained champions. Freeze onboarding of new sites if unresolved incident threatens custody or finance. Keep old Excel read-only after cutover; only numbered outage ledger can add exception transactions, later reconciled.
