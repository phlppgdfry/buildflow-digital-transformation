# Release readiness checklist

## Target production — gates remain open

- [ ] Business requirements/process decisions and scope signed by owners.
- [ ] ERP sandbox contract, query-by-reference and financial reconciliation verified.
- [ ] Entra tokens, project RBAC, no-self-approval and document access tested.
- [ ] Power Platform licences, DLP, regions, connectors and support approved.
- [ ] Retention/privacy/processor review completed; safe evidence scanning implemented.
- [ ] Pilot masterdata unique, labels verified; source mappings and restore evidence attached.
- [ ] UAT executed; no Sev1/2 open; accessibility/field tests accepted.
- [ ] Migration, cutover, rollback and backup restore rehearsed.
- [ ] Support rota, dashboard, escalation owners, champions and training ready.
- [ ] Business Owner, Warehouse, Finance and IT sign-off recorded.

## Public portfolio readiness

- [x] Synthetic case/no employer information stated.
- [x] Design vs executable demo boundary explicit.
- [x] Analysis-to-test/outcome traceability maintained.
- [x] Local commands, artefact validation and browser evidence documented in audit.

A public GitHub release is not a production rollout of a business system.
