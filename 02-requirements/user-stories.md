# User stories

## US-01

As a warehouse manager, I need to identify each asset with an immutable ID and QR label, so that staff can record custody against the correct equipment. Acceptance: [AC-01](acceptance-criteria.md#ac-01). Priority: Must.

## US-02

As a warehouse operator, I need to check out an available asset to a valid site and active custodian, so that its location and responsibility are explicit. Acceptance: [AC-02](acceptance-criteria.md#ac-02). Priority: Must.

## US-03

As a warehouse operator, I need to inspect an asset before releasing it for reuse and create a linked Draft claim when damaged, so that unsafe equipment stays out of circulation. Acceptance: [AC-03](acceptance-criteria.md#ac-03). Priority: Must.

## US-04

As a receiving site supervisor, I need to confirm receipt against a dispatched transfer, so that custody changes only after the destination accepts the asset. Acceptance: [AC-04](acceptance-criteria.md#ac-04). Priority: Must.

## US-05

As an auditor, I need to inspect append-only movement and status history, so that I can reconstruct custody without altering prior records. Acceptance: [AC-05](acceptance-criteria.md#ac-05). Priority: Must.

## US-06

As a warehouse manager, I need to control reservation, maintenance, loss and retirement transitions, so that assets can only circulate when their operational state allows it. Acceptance: [AC-06](acceptance-criteria.md#ac-06). Priority: Must.

## US-07

As a site employee, I need to register a claim with its asset, site, factual description and restricted evidence, so that the coordinator can investigate a complete record. Acceptance: [AC-07](acceptance-criteria.md#ac-07). Priority: Must.

## US-08

As a claims coordinator, I need to request missing information while retaining the original SLA clock, so that incomplete claims remain accountable and visible. Acceptance: [AC-08](acceptance-criteria.md#ac-08). Priority: Must.

## US-09

As an authorised manager, I need to approve the current claim revision within the delegation rules and require Finance above €5,000, so that repair commitments receive independent approval without self-approval. Acceptance: [AC-09](acceptance-criteria.md#ac-09). Priority: Must.

## US-10

As a Finance controller, I need approved repair commitments queued to ERP and posted invoice actuals reconciled, so that operational estimates never replace financial accounting. Acceptance: [AC-10](acceptance-criteria.md#ac-10). Priority: Must.

## US-11

As an operations manager, I need overdue claims to generate deduplicated reminders and escalations, so that owners act without repeated notification noise. Acceptance: [AC-11](acceptance-criteria.md#ac-11). Priority: Should.

## US-12

As a mobile employee, I need to save an unconfirmed offline draft and validate it online before confirming custody, so that poor connectivity does not create false stock availability. Acceptance: [AC-12](acceptance-criteria.md#ac-12). Priority: Must.

## US-13

As a claims coordinator, I need an optional AI draft that I can review or reject, so that facts can be structured faster while business decisions remain human. Acceptance: [AC-13](acceptance-criteria.md#ac-13). Priority: Could.

## US-14

As a business owner, I need reporting with explicit denominators, scope and completeness, so that operational comparisons are meaningful. Acceptance: [AC-14](acceptance-criteria.md#ac-14). Priority: Should.
