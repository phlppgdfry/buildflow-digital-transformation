# User stories

## US-01

As a Warehouse manager, I need to register and identify asset with immutable ID and QR, so that accountable asset custody is supported. Acceptance: [AC-01](acceptance-criteria.md#ac-01). Priority: Must.

## US-02

As a Warehouse operator, I need to check out available asset to valid site and active custodian, so that accountable asset custody is supported. Acceptance: [AC-02](acceptance-criteria.md#ac-02). Priority: Must.

## US-03

As a Warehouse operator, I need to inspect return before releasing asset; damaged return creates linked Draft claim, so that safe returns is supported. Acceptance: [AC-03](acceptance-criteria.md#ac-03). Priority: Must.

## US-04

As a Receiving site supervisor, I need to dispatch and confirm transfer with sender custody until receipt, so that accountable asset custody is supported. Acceptance: [AC-04](acceptance-criteria.md#ac-04). Priority: Must.

## US-05

As a Auditor, I need to record append-only movement/status history, so that accountable asset custody is supported. Acceptance: [AC-05](acceptance-criteria.md#ac-05). Priority: Must.

## US-06

As a Warehouse manager, I need to control reservation, maintenance, loss and retirement transitions, so that safe returns is supported. Acceptance: [AC-06](acceptance-criteria.md#ac-06). Priority: Must.

## US-07

As a Site employee, I need to create claim with asset/site, description and restricted evidence, so that timely documented claims is supported. Acceptance: [AC-07](acceptance-criteria.md#ac-07). Priority: Must.

## US-08

As a Claims coordinator, I need to triage and request missing information with original SLA clock, so that timely documented claims is supported. Acceptance: [AC-08](acceptance-criteria.md#ac-08). Priority: Must.

## US-09

As a Authorised manager, I need to manager approval plus Finance when estimate >€5,000; no self-approval, so that controlled financial processing is supported. Acceptance: [AC-09](acceptance-criteria.md#ac-09). Priority: Must.

## US-10

As a Finance controller, I need to queue approved repair commitment to ERP and reconcile invoice actuals, so that controlled financial processing is supported. Acceptance: [AC-10](acceptance-criteria.md#ac-10). Priority: Must.

## US-11

As a Operations manager, I need to send idempotent SLA reminders and escalation, so that timely documented claims is supported. Acceptance: [AC-11](acceptance-criteria.md#ac-11). Priority: Should.

## US-12

As a Mobile employee, I need to save offline draft; require online validation before confirmed custody, so that trusted field experience is supported. Acceptance: [AC-12](acceptance-criteria.md#ac-12). Priority: Must.

## US-13

As a Claims coordinator, I need to generate optional reviewable AI structure without decision rights, so that timely documented claims is supported. Acceptance: [AC-13](acceptance-criteria.md#ac-13). Priority: Could.

## US-14

As a Business owner, I need to report explicit denominators, project scope and completeness, so that comparable operational insights is supported. Acceptance: [AC-14](acceptance-criteria.md#ac-14). Priority: Should.
