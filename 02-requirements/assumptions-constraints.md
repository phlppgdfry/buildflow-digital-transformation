# Assumptions and constraints

| ID | Assumption / constraint | Consequence if false | Validation owner |
|---|---|---|---|
| AS-01 | ERP has incremental API/export and stable IDs | Scheduled CSV staging with quarantine; no uncontrolled writes | IT |
| AS-02 | Users licensed appropriately for target Power Platform | Reprice or compare custom app before build | IT manager |
| AS-03 | 2,000 physical assets can be labelled | Plan physical sweep; unlabelled assets cannot enter pilot circulation | Warehouse |
| AS-04 | Managers have delegations and project ownership | Stop unresolved approvals; owner matrix needed | Operations |
| AS-05 | Mobile devices can reach online service sometimes | Outage form and draft; no guaranteed offline confirmation | IT + Key User |
| AS-06 | Photos can be minimised and retained for a defined purpose | No unreviewed evidence storage; privacy gate | Privacy adviser |

Constraints: no real employer data; no ERP replacement; no automatic legal liability; no production deployment claimed. Cloud region, processor agreement, licence price and ERP vendor remain deliberately unspecified until actual procurement discovery.
