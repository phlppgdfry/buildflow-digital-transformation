# Official OMG BPMN schema snapshot

These unmodified XSD files were downloaded on 7 October 2026 from the [OMG BPMN 2.0 machine-readable schema](https://www.omg.org/spec/BPMN/20100501/BPMN20.xsd) and its relative imports (Semantic, BPMNDI, DC, DI). They preserve their original namespace definitions and notices. They are a third-party validation reference; the repository MIT licence does not relicense OMG materials.

Run `python3 scripts/check-bpmn-xsd.py` with system `xmllint` available (macOS ships it; Ubuntu package `libxml2-utils`). This verifies schema structure, not engine executability or the correctness of every business decision.
