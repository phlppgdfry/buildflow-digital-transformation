# Workshop preparation

**Purpose:** agree custody handoffs and claim approval boundaries, then produce prioritised requirements. Not a tool-selection meeting. Sponsor: Operations; facilitator: Transformation Analyst; scribe: Key User.

Participants: Warehouse manager and operator, Site supervisor, Project manager, Finance, Procurement, Operations, IT integration developer, mobile employee. Privacy adviser reviews outputs afterwards.

Beforehand: anonymised example spreadsheets, three recent-style incident timelines, project list, asset master export and connectivity observations. All supplied examples in this case are synthetic. Count missing serial numbers and duplicate IDs; do not merge automatically.

Send a one-page scope and definitions: custody ≠ legal liability; estimated cost ≠ actual invoice. Ask each participant for one failure and one workaround. Collect no employee performance ranking.

Outputs: signed-off process boundary, actors/events, pain-point root causes, MoSCoW backlog, open questions, owners/due dates and process decisions. Store disagreements with rationale. Validation: circulate notes within two working days; explicitly request corrections from quieter field participants.
